# What other children's learning apps have that Beszéd didn't

October 2026. A sweep of children's education apps, web game portals, speech-therapy apps and early-years
programmes, compared game by game with Beszéd's 50 games. This list is what came out, and what was built from it.

## How it was made

- **Where we looked** (8 sweeps, about 420 searches and page reads):
  - all-in-one preschool apps: Khan Academy Kids, Lingokids, Kiddopia, HOMER, Duolingo ABC, PBS KIDS, Bimi Boo,
    BabyBus, Papumba, Edoki, Pok Pok;
  - literacy and phonics apps: Endless Alphabet/Reader, Teach Your Monster to Read, Reading Eggs, Phonics Hero,
    LetterSchool, Starfall, Ello, Amira;
  - speech-therapy apps: Speech Blubs, Articulation Station, Apraxia Ville, Otsimo, Tiga Talk, Hamaguchi,
    Splingo, Bitsboard, Boom Cards SLP decks;
  - maths, logic and coding apps: Moose Math, Endless Numbers, DragonBox, Think!Think!, LogicLike, MentalUP,
    Osmo, Bee-Bot, Kodable, Lightbot Jr, ScratchJr;
  - creative, feelings and music apps: Toca Boca, Sago Mini, Daniel Tiger, Breathe Think Do, GoNoodle,
    Chrome Music Lab, Mussila;
  - web portals: ABCya, Turtle Diary, Sheppard Software, Highlights Hidden Pictures, CBeebies, Toy Theater;
  - the Hungarian market: Okos Doboz, LOGICO Primo, Bogyó és Babóca, superprof logopédiai játékok, the Sindelar
    programme, GMP;
  - the research on phonological awareness, auditory processing, narrative and executive function.
- **What came out:** 148 distinct game types. Each was checked against Beszéd's code and content:
  - 37 Beszéd already has;
  - 51 it has in part (the same task with different content, or one level of another game);
  - 60 it was missing.
- **What was built:** the 20 games below. The judging criteria were:
  - speech and language first;
  - how many successful apps have the game;
  - Hungarian kindergarten and logopédia practice;
  - whether it can be done without image or audio files (Twemoji pictures, pictures drawn in code, Csillám's
    voice, sounds made in the browser).

## Already covered

Beszéd already had these, so they were left out:

- syllable counting, first sound, rhymes, minimal-pair listening;
- following directions, categories and odd one out, patterns, picture sequencing;
- sentence repetition, story comprehension, decoding by syllables, spelling from tiles;
- letter tracing, counting and comparing, the number line, balance and sharing;
- clock reading, memory and Simon games, spot the difference, jigsaws, oral-motor exercises.

## Follow-ups found while building

- **Held sounds in the voice.** Both TTS voices spell out text with no vowel ("sssz" is read "es es es zé") and Piper reads "…" aloud. So the games name sounds by their letter plus a helper ("az sz hang, a kígyó sziszegése"). Real held sounds (and blending single sounds, "k-a-p-u") need SSML `<phoneme>` support in AzureTtsClient, or recorded models.
- **Voice game thresholds.** Fújóka and Hangrepülő were tuned on synthetic signals; check the blow/loudness thresholds on real phones (and iOS noise suppression).
- **Recycling pictures.** Twemoji has few clear packaging pictures: the glass bin has 2, the yellow bin 4. Adding pictograms would help.
- **Per-sound report.** Hanggyakorló practice is not yet counted in the parents' per-sound progress (SoundProgress).
