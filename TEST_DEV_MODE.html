Memory Game Difficulty Selector

✅ Difficulty Levels Implemented

The Párkereső (memory game) now has 3 difficulty levels with different timings and grading.

🟢 Easy Mode

Flip-back: 1400ms
Grading: Always 2-3 stars
Feel: Relaxed & encouraging

🟡 Medium Mode

Flip-back: 1100ms
Grading: Standard (0-1 = 1⭐, 2 = 2⭐, 3+ = 3⭐)
Feel: Balanced

🔴 Hard Mode

Flip-back: 800ms
Grading: Strict (0 = 1⭐, 1 = 2⭐, 2+ = 3⭐)
Feel: Challenging
