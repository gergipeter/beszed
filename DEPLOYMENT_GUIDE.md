### Environment Setup

Create `.env` file in project root:

```bash
# App Config
APP_NAME="Beszéd"
APP_ENV=production
APP_KEY=base64:... # Run: php artisan key:generate
APP_DEBUG=false
APP_URL=https://your-domain.com

# Database (MySQL on horizon-mysql)
DB_CONNECTION=mysql
DB_HOST=horizon-mysql
DB_PORT=3306
DB_DATABASE=beszed
DB_USERNAME=beszed
DB_PASSWORD=your-secure-password

# Redis (for leaderboards & real-time)
REDIS_HOST=redis
REDIS_PASSWORD=null
REDIS_PORT=6379
CACHE_DRIVER=redis
SESSION_DRIVER=cookie

# Queue (for async jobs)
QUEUE_CONNECTION=redis

# Mail (for notifications)
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=your-username
MAIL_PASSWORD=your-password
MAIL_FROM_ADDRESS=noreply@beszed.com
MAIL_FROM_NAME="Beszéd"

# Storage (for audio & PDFs)
FILESYSTEM_DRIVER=local
FILESYSTEM_VISIBILITY=private

# APIs
OPENAI_API_KEY=sk-... # Get from OpenAI dashboard
OPENAI_ORG_ID=org-... # Optional

# Sanctum (Auth)
SANCTUM_STATEFUL_DOMAINS=localhost,your-domain.com

# Encryption
APP_CIPHER=AES-256-CBC
ENCRYPTION_KEY=... # Generated by key:generate

# Trusted Proxies (if behind load balancer)
TRUSTED_PROXIES=*
```

## Step 1: Database Setup

### 1.1 Create Database
```bash
# Connect to MySQL
mysql -h horizon-mysql -u root -p

# Create database and user
CREATE DATABASE beszed CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'beszed'@'%' IDENTIFIED BY 'your-secure-password';
GRANT ALL PRIVILEGES ON beszed.* TO 'beszed'@'%';
FLUSH PRIVILEGES;
```

### 1.2 Run Migrations

```bash
# Connect to container or server
cd /var/www/html

# Run all migrations
```

## Step 2: Backend Deployment

### 2.1 Docker Setup

**Dockerfile:**
```dockerfile
FROM php:8.3-fpm-alpine

RUN apk add --no-cache \
    curl \
    mysql-client \
    redis \
    libsodium-dev

RUN docker-php-ext-install \
    pdo_mysql \
    redis \
    sodium

WORKDIR /var/www/html
COPY . .

RUN chmod -R 775 storage bootstrap/cache

EXPOSE 9000
```

**docker-compose.yml:**
```yaml
version: '3.8'
services:
  app:
    build: .
    ports:
      - "8000:9000"
    environment:
      - DB_HOST=mysql
      - REDIS_HOST=redis
    volumes:
      - .:/var/www/html
    depends_on:
      - mysql
      - redis

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_DATABASE: beszed
      MYSQL_USER: beszed
      MYSQL_PASSWORD: password
      MYSQL_ROOT_PASSWORD: root
    volumes:
      - mysql_data:/var/lib/mysql

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  mysql_data:
  redis_data:
```

### 2.2 Deploy Code

```bash
# Copy files to container
docker cp app/ beszed-app-1:/var/www/html/
docker cp routes/ beszed-app-1:/var/www/html/
docker cp database/ beszed-app-1:/var/www/html/

# Install dependencies
docker exec beszed-app-1 composer install --no-dev --optimize-autoloader

# Clear cache (NOT config:cache due to APP_KEY issue)
docker exec beszed-app-1 php artisan cache:clear
docker exec beszed-app-1 php artisan view:clear
docker exec beszed-app-1 php artisan route:clear
```

## Step 6: Production Security

### 6.1 Enable HTTPS

```bash
# Configure reverse proxy (nginx)
server {
    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location ~ \.php$ {
        fastcgi_pass app:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

### 6.2 Database Security

```sql
-- Change default password
ALTER USER 'beszed'@'%' IDENTIFIED BY 'strong-password-here';

-- Create read-only user for analytics
CREATE USER 'beszed_read'@'%' IDENTIFIED BY 'read-password';
GRANT SELECT ON beszed.* TO 'beszed_read'@'%';

-- Enable binary logging for audit trail
SET GLOBAL binlog_format = 'ROW';
```

### 6.3 API Rate Limiting

In `app/Http/Middleware/ThrottleRequests.php`:

```php
Route::middleware('throttle:60,1')->group(function () {
    Route::post('/api/speech/analyze', ...);
});
```

### 6.4 Encryption Keys

```bash
# Generate encryption key
php artisan key:generate

# Generate Sanctum key
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"
```

## Troubleshooting

### API Returns 401 Unauthorized

```bash
# Check Sanctum configuration
php artisan tinker
>>> config('sanctum.stateful_domains')
=> ["localhost", "your-domain.com"]

# Verify CSRF token
# Check cookie settings
```

### Database Connection Error

```bash
# Test connection
mysql -h horizon-mysql -u beszed -p beszed -e "SELECT 1;"

# Check MySQL is running
docker ps | grep mysql
```

### Redis Connection Failed

```bash
# Check Redis is running
redis-cli -h redis ping
=> PONG

# Check Redis config in .env
REDIS_HOST=redis
REDIS_PORT=6379
```

### Speech Analysis Timeout

```bash
# Increase timeout in config
# Check OpenAI API limits
# Monitor audio file size (max 25MB)
```

### Frontend Components Not Loading

```bash
# Verify components are built
ls -la public/js/
```
